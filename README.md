# E-Commerce-Sales-Dashboard-PowerBI

## Project Overview
An interactive Power BI dashboard developed to analyze e-commerce sales performance and generate business insights.

## Tools Used
- Power BI
- Excel
- Power Query
- DAX

## Dashboard Features
- Total Sales
- Total Quantity
- Total Profit
- Average Order Value
- Sales by State
- Quantity by Category
- Profit by Month
- Sales by Customer
- Quantity by Payment Mode
- Profit by Sub-Category
- Quarter-wise Analysis

## Skills
- Data Cleaning
- Data Transformation
- Data Modeling
- DAX
- Data Visualization
- Dashboard Development
